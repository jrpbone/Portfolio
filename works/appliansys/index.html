Case study

Challenge

An appliance storefront must coordinate product discovery, customer accounts, inventory, checkout, fulfillment, order tracking, and administrative reporting.

Approach

I built the customer storefront and REST API as connected journeys, including search, database-backed carts, delivery or pickup, mock GCash payments, and order status.

System architecture

System Architecture

Storefront and operations flow
Storefront React + Material UI Redux-managed customer journeys
→
Backend Express REST API Commerce and admin workflows
→
Database MySQL Products, carts, and orders
Connected services
  • OpenAI customer support
  • Leaflet delivery maps
  • ExcelJS + jsPDF exports

Engineering decisions

React, Material UI, and Redux Toolkit manage the customer experience; Express and MySQL support role-based admin tools, stock controls, reports, maps, and document exports.

Outcome

The platform connects customer purchasing and internal operations while providing AI-assisted support and a clear administrative view of products, orders, and sales.
